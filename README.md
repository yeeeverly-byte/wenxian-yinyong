# 文献引用

面向中西文混排、尤其是数字人文与人文学英文写作的文献引用技能。输入书名、篇名或书目草稿后，先核对权威目录与史料库中的书目信息，再按约定体例生成可直接粘贴的英文参考文献。

This is a reusable skill for formatting English-language bibliographies that mix Chinese primary sources, modern Chinese scholarship, and Western theory. It verifies bibliographic data, then produces a copy-pasteable reference list with consistent typography, naming, and translation rules.

## 它解决什么问题

人文学和数字人文的英文论文，经常需要同时引用三类材料：古籍及其现代整理本、中文研究论著，以及西方理论著作。这三类文献的责任者、版本、卷次和题名处理方式并不相同。如果只把中文书名一律改成英文，读者难以回查原书；如果只保留中文，国际读者又不易检索。人名是否附汉字、书名是否另拟英译、出版年放在作者之后还是出版项末尾，也常因体例不统一而反复修改。

本技能把这些判断写成可重复执行的规则：先确认“引用的是哪一个版本”，再按目标体例排出可提交的参考文献，而不是只做格式替换。

## 适用场景

适合在下列情况下使用：

- 准备向国际会议或期刊投稿的英文论文，尤其是数字人文、文学史、艺术史等相关领域，需要一份中西文混排的 References。
- 手中已有按中文学术规范（如 GB/T 7714）整理的书目，要改写成 Chicago 或 APA，并处理古籍卷次、点校者和现代整理本信息。
- 只记得书名、篇名或一条不完整的引用，需要补全作者、版本、出版项或期刊卷期页码。
- 同一文献在草稿中出现多次（例如既写了《太平广记》某卷，又写了同一整理本的全书条目），需要去重并统一著录。
- 文献已经自行核对，只需要一份可复制、可直接贴进论文的定稿，不要再附加“待核”或考证说明。
- 临时改投另一种体例，或需要带真实斜体（而非星号标记）的 Word 文件。

如果目标会议或期刊已经提供专属稿约或样例，应以稿约为准；本技能的默认体例是国际人文学常用的 Chicago 注释—书目制，而不是对某一学会格式的假定。

## 功能

### 1. 自动核查书目信息

在用户未声明“已经核对”时，根据文献类型查询较权威的来源：

- 中国古籍与整理本：核对撰者或编纂者、现代点校者或注者、版次、册数、出版地、出版社和出版年。识典古籍、中国哲学书电子化计划、维基文库等可作为查找线索，但参考文献应著录实际使用的整理本或刻本。
- 中文今人专著与期刊论文：核对作者、题名、刊名、卷期、年份和页码，依据期刊官网、馆藏目录或论文首页。
- 西方著作与论文：依据出版社页面、图书馆目录或 DOI，确认译本、译者、出版者和出版年，并与实际使用的版本保持一致。

不编造年份、页码、ISBN、DOI 或版本说明。无法确认的信息会省略或单独标明。

### 2. 版本认定与去重

同一作品若被写成两条（例如古籍单篇与其现代整理本），会合并为一条，并著录用户实际使用的版本。古籍的卷、篇、页码放到注释或文内引用中，不写进参考文献的书名里。古代的“卷”（juan）与现代装订的册数（vols.）分开处理。

### 3. 字体与编排

- 书名、期刊名为斜体，拼音和中文原题放在同一斜体范围内，例如 *Taiping guangji 太平广记*。
- 篇名、章节名不加斜体：拼音题名加引号，其后保留中文原题，例如 “Yulunpao zhuan” 郁轮袍传。
- 中文简繁体保持用户或底本原样，不做相互转换，以免改错字。
- 拼音默认不加声调，除非投稿规范要求。
- 删除 `[M]`、`[J]` 等文献类型标记；除非用户要求编号列表，否则不保留原稿编号。

### 4. 翻译与不翻译

- 不为中文书名或篇名另拟英文译名，也不在方括号中添加自拟翻译。
- 如果实际引用的是已出版的英译本，则使用该译本的正式英文书名，并列出译者与该本的出版项。
- 中文文献的个人作者、编者、点校者、注者：同时给出罗马字和汉字，例如 Xia Hanyi 夏含夷、Li, Fang 李昉。
- 机构或集体作者可以只保留罗马字，例如 Shanghai guji chubanshe, ed.
- 英文文献的西方作者不加汉字。

### 5. 分类排版

当论文同时使用原始文献、历史或文学研究、理论著作时，参考文献默认分为三组，每组按罗马字作者姓氏字母排序：

- **Primary Sources and Editions**：原文及其现代校注、点校本
- **Historical and Literary Scholarship**：关于这些材料的今人专著与论文
- **Theoretical Works**：各语种理论著作

若投稿规范要求单一按字母排序的 References，再合并为一表。

### 6. 已核对模式与体例切换

用户声明文献已经核对后，直接依据其提供的数据输出定稿，不再附加待核标记、考证或史料真伪讨论。若之后提供会议或期刊模板，只改体例，不重新争论已核对的事实。

## 使用方法

### 在对话中调用

在 Cursor 或 Grok Bot 中，可用 `/` 或 `@` 选择本技能，也可以直接发送文献名或书目草稿。技能被调用后，应先核查再排版，最后给出可复制的列表。

建议在输入中说明：

- 文献是否已经自行核对
- 目标体例（默认 Chicago 注释—书目制；也可指定 APA、作者—年份制，或粘贴会议样例）
- 是否需要可在 Word 中保持斜体的 `.docx` 文件

### 常见输入方式

- 只给书名或篇名，例如“《太平广记》卷179 王维”
- 粘贴尚未统一格式的中英混合书目
- 粘贴中文规范格式的参考文献，要求改写成英文投稿格式
- 补充一条新文献，要求按已有体例追加

### 安装

将本仓库中的 `SKILL.md` 加入 Cursor 或 Grok Bot 的技能库即可使用。若你已经在对话里保存了同名技能，以技能库中的版本为准，并可用本仓库中的文件进行同步或分享。

## 默认条目格式

Chicago 注释—书目制下，年份放在出版项末尾。

著作：

```text
Author, Given 汉字. *Romanized title 中文题名*. Edited / punctuated / translated by Name 汉字. x vols. Place: Publisher, year.
```

期刊论文：

```text
Author, Given 汉字. "Romanized article title" 中文篇名. *Romanized journal 中文刊名* vol, no. x (year): pages.
```

示例如下。

```text
Li, Fang 李昉, et al., comps. *Taiping guangji 太平广记*. Punctuated and collated by Wang Shaoying 汪绍楹. 10 vols. Beijing: Zhonghua shuju, 1961.

Zhou, Zheda 周哲达. “‘Jiyi ji · Wang Wei’ benshi kaolun”《集异记·王维》本事考论. *Bohai daxue xuebao (zhexue shehui kexue ban) 渤海大学学报（哲学社会科学版）* 41, no. 3 (2019): 132–136.

Thrift, Nigel. *Non-Representational Theory: Space, Politics, Affect*. Milton Park, Abingdon, Oxon: Routledge, 2007.
```

文内或注释中再给出具体定位，例如《太平广记》卷 179〈王维〉及页码，而不把卷次写进参考文献书名。
